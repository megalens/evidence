Every price and free-plan claim for the seven other tools on the page, with a dated public copy of the
vendor page it was read from. The copies were saved to the Internet Archive on **25 September 2026**,
the same day each claim was checked again on the live page. Prices change, so a copy from a later date
may differ; the saved copy shows what the page said on that day.

**Tabs and toggles.** Bito's monthly prices, Snyk's small-team prices and CodeRabbit's open source answer
sit behind a tab, toggle or expandable question. The saved copy holds the page as first loaded; where the
archived page does not run the tab, the live page above is the check.

**Our own captures.** We also kept the page text and a full-page screenshot of each vendor page as we
read it on 25 September 2026. They are the vendors' own pages, so we do not republish them;
`captures.sha256` fingerprints each one, and we can share them with anyone who wants to compare.

MegaLens's own row on the page describes our product, not a vendor page, and is not part of this folder.
